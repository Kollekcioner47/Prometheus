# files/05_grafana — файлы практики 5

Здесь лежат файлы, которые изучаются в практике 5 «Grafana: установка
из зеркала Яндекса и первый дашборд». Студент набирает всё это
руками вместе с преподавателем; каталог нужен, чтобы взять готовое,
если что-то не набралось.

| Файл | К какому шагу | Что это |
|---|---|---|
| `grafana.list` | Шаг 5 | файл apt-репозитория зеркала Яндекса |
| `key_import.txt` | Шаг 5 | команды получения и установки ключа подписи Grafana Labs |
| `grafana.ini.fragment` | Шаг 6 | настройки Grafana, которые меняются в курсе |
| `provisioning/datasources/prometheus.yml` | Шаг 12 | источник данных Prometheus как код |
| `provisioning/dashboards/lab.yml` | Шаг 12 | правило загрузки дашбордов из каталога |
| `dashboards/lab-overview.json` | Шаг 12 | дашборд «Состояние парка» |
| `dashboard_ids.md` | Шаг 11 | готовые дашборды с grafana.com и их номера |

## Правила

- Готовых решающих скриптов здесь нет и быть не должно: всё, что
  в этом каталоге лежит, — это конфигурация, а не программа.
  `key_import.txt` — текстовые команды для ручного выполнения,
  а не исполняемый файл.
- Содержимое каждого файла напечатано и в самой практике. Если
  файл и текст практики разойдутся, прав тот, кто написал практику:
  сначала правится практика, потом файл.
- Версия Grafana в курсе зафиксирована — 12.0.10. Имя пакета
  на зеркале содержит номер сборки (`grafana_12.0.10_21942624936_linux_amd64.deb`),
  и его всегда берут из листинга каталога, а не набирают по памяти.

## Чего здесь нет

Здесь нет архива пакета и нет `gpg.key`. Пакет скачивается
на занятии с зеркала, а ключ подписи — с машины, у которой есть
доступ к `apt.grafana.com`; оба файла слишком велики или зависят
от даты, чтобы хранить их в репозитории курса.
