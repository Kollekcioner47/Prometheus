ПОЛУЧЕНИЕ И УСТАНОВКА КЛЮЧА ПОДПИСИ GRAFANA LABS
=========================================================================

Пакеты в репозитории Grafana подписаны ключом Grafana Labs.
apt обязан этот ключ знать, иначе установка из репозитория
не пройдёт. Публичный ключ лежит по адресу

    https://apt.grafana.com/gpg.key

и этот адрес из российских сетей недоступен. На зеркале Яндекса
файла с ключом нет (проверка: GET на
https://mirror.yandex.ru/mirrors/packages.grafana.com/oss/deb/gpg.key
возвращает 404). Поэтому ключ приносят файлом.

ДЕЙСТВИЕ 1 — НА МАШИНЕ С ДОСТУПОМ (не на стенде курса)
=========================================================================

    curl -fsSL https://apt.grafana.com/gpg.key -o grafana.gpg.key

Проверьте, что скачался именно ключ, а не страница ошибки:

    file grafana.gpg.key
    head -1 grafana.gpg.key

Первая строка должна начинаться с -----BEGIN PGP PUBLIC KEY BLOCK-----

Перенесите файл grafana.gpg.key на машину mon любым доступным
способом. В курсе это делается копированием файла через буфер
обмена виртуальной машины или через scp, если у вас есть третья
машина с доступом.

ДЕЙСТВИЕ 2 — НА МАШИНЕ mon
=========================================================================

    sudo mkdir -p /etc/apt/keyrings
    sudo gpg --dearmor -o /etc/apt/keyrings/grafana.gpg < grafana.gpg.key
    sudo chmod 644 /etc/apt/keyrings/grafana.gpg

Подключите репозиторий зеркала с указанием ключа:

    sudo tee /etc/apt/sources.list.d/grafana.list > /dev/null <<'EOF'
    deb [signed-by=/etc/apt/keyrings/grafana.gpg] https://mirror.yandex.ru/mirrors/packages.grafana.com/oss/deb stable main
    EOF

    sudo apt update
    sudo apt install -y grafana

Ожидаемый результат apt update: строка с адресом зеркала
и без предупреждений вида

    W: GPG error: https://mirror.yandex.ru/... The following signatures couldn't be verified

ЕСЛИ КЛЮЧА НЕТ И ВЗЯТЬ ЕГО НЕГДЕ
=========================================================================

Есть три пути, и все три разобраны в практике 5, шаг 5:

  1. поставить пакет из каталога pool зеркала — ключ при этом
     не нужен вообще (основной способ курса);
  2. извлечь ключ из пакета, скачанного вручную;
  3. временно поставить репозиторий с [trusted=yes] — и обязательно
     убрать эту настройку после занятия.

Параметр trusted=yes отключает проверку подписи репозитория.
На боевой машине так делать нельзя: подмена ответа зеркала или
DNS-записи приведёт к установке произвольного пакета.
