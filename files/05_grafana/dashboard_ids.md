ГОТОВЫЕ ДАШБОРДЫ С GRAFANA.COM
=========================================================================

Дашборд — это обычный JSON с запросами. Он не выполняет кода
и ничего не меняет в системе, поэтому его можно спокойно нести
файлом.

ВАЖНО: сам сайт grafana.com из российских сетей недоступен.
Импорт по номеру (Dashboards → New → Import → Import via
grafana.com) на занятии часто не срабатывает: Grafana не может
скачать JSON с сайта. В этом случае JSON приносят файлом:

    Dashboards -> New -> Import -> Upload JSON file

ПОЧЕМУ ВЕРСИИ ДАШБОРДОВ РАЗНЫЕ ПО КАЧЕСТВУ
=========================================================================

Дашборд с grafana.com пишут такие же люди, как вы. Часть дашбордов
заброшена, часть рассчитана на другую версию экспортёра, часть
содержит запросы, которые положат Prometheus на большом объёме.

Поэтому оба правила из практики действуют всегда:

  * перед импортом посмотрите, какие запросы выполняет дашборд;
  * не импортируйте дашборд с запросами на месяц истории
    в высоконагруженную систему.

ЧЕГО НЕ ДЕЛАТЬ
=========================================================================

  * не правьте импортированный дашборд в браузере, если он нужен
    другим: правка уйдёт в вашу копию, и версии разойдутся;
  * не выдавайте ссылку с параметром kiosk вместо нормальных прав
    доступа: это скрывает меню, а не закрывает данные;
  * не публикуйте дашборд с адресами и именами хостов за пределы
    организации.
