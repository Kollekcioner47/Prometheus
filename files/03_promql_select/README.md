# files/03_promql_select — файлы практики 3

Каталог относится к практике 3 «PromQL: выборка и фильтрация».

## Что здесь лежит

* `queries.promql` — все запросы практики, по одному в строке,
  с комментариями. Порядок тот же, что в практике: сначала
  выборка и метки, затем время и отсутствие данных.

## Как пользоваться

Файл не запускается и никуда не подключается: это справочник.
Запросы из него набираются в поле Expression на странице
`http://10.0.2.5:9090/graph`, по одному, с нажатием `Execute`.

Многострочный запрос в PromQL остаётся одним выражением:
перенос строки внутри выражения допустим, точка с запятой — нет.
В этом файле каждый запрос записан одной строкой, потому что
так его удобно копировать в поле запроса.

Проверить запрос без браузера можно через API:

    curl -s 'http://localhost:9090/api/v1/query?query=up' | head -c 400

Ответ приходит в JSON. Поле `"resultType":"vector"` означает,
что запрос вернул мгновенный вектор; для диапазонного вектора
ответа быть не может — диапазонный вектор всегда аргумент
функции, а не самостоятельный результат.

## Чего в каталоге нет

Готовых скриптов: `.sh`, `.ps1`, `.bat` здесь лежит не должно,
и не лежит. Запрос, написанный преподавателем и запущенный
скриптом, ничему не учит: разница между селектором и функцией
видна только тогда, когда запрос набран и выполнен руками.
